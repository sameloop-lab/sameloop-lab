The square PNG is a proposed identity, generated with the built-in Imagegen tool.
It depicts two loop paths and circuit nodes, in navy/teal/vermilion on ivory,
with no text. The full image is retained without post-processing.
The [generation prompt](image-prompt.txt) is included for later revisions.

[profile-README.md](profile-README.md) is a template for the organization's
profile: place its contents in `profile/README.md` in a public repository named
`.github` under the organization. This file's presence in the umbrella repository
alone does not configure the organization profile. Nothing was uploaded to GitHub.
