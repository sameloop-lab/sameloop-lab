# Bind & Seek — presentation material

Proposed title: **Bind & Seek: Same Control Loop, Different Embedded Stacks**.
The first presentation should focus on AFB and KUKSA, the common contract,
communication boundaries, failure behavior and reproducible evidence.

Hardware, security, test infrastructure and beginner onboarding are possible
independent contributions. OpenHarmony/webOS remain future integrations.
No FOSDEM acceptance, submission or speaker commitment is claimed here.

Use the functional diagram first, then one architecture at a time. Keep the
limitations visible: different numerical models, unconnected GUIs, no complete
AGL image and no physical bench validation. Future fault injection could extend
the story to “same loop, same faults, compared reactions”.
