SameLoop Lab

Bind & Seek — Same Control Loop, Different Embedded Stacks.

We explore embedded service architectures through one temperature-and-fan demo. The project combines a shared functional contract, native middleware integrations, simulation, failure scenarios and documented evidence.

Start with sameloop-lab. Initial component deliveries cover AFB and KUKSA on Linux; other integrations, connected graphical interfaces and hardware qualification remain in progress or planned.
