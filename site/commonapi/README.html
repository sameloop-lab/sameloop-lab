CommonAPI / SOME-IP — optional, planned

Proposed project sameloop-commonapi: generated proxy/stub, C++ service and SOME/IP transport using a qualified runtime. This is an extension, not a required fifth platform for the first demonstration. TLS support must not be assumed from the mere use of TCP. No implementation or test is delivered here.

References: https://github.com/COVESA/capicxx-someip-runtime and https://github.com/COVESA/vsomeip
