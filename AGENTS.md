# Contributor automation instructions

Read README.md and docs/deviations.md. Public prose is English; imported French
diagrams/evidence retain their source language. Keep status and evidence distinct.
Edit data/projects.json and DOT/Markdown sources, then npm ci, npm run build,
npm run check. Inspect any changed diagrams. Do not invent repository URLs,
performance numbers, target validation or connected GUI support. Do not publish
or change organization settings without an explicit instruction.
